# Idiomas (español e inglés)

Wayly está en español e inglés sin librerías externas ni builds por idioma.

## Cómo funciona

- `src/app/core/i18n/messages.es.ts` es la **fuente de verdad**. Su forma define el tipo `Messages`.
- `src/app/core/i18n/messages.en.ts` está tipado como `Messages`: si falta una clave, **no compila**.
- `MessageKey` es la unión de todas las claves con puntos (`nav.theme.dark`), así que una clave mal escrita tampoco compila.
- Las pruebas de `i18n.service.spec.ts` comprueban además que los dos idiomas tienen las mismas claves, los mismos marcadores `{nombre}` y ningún texto vacío.

## Idioma inicial

1. El que el usuario eligió (guardado en `localStorage` como `wayly.language`).
2. `?lang=es` o `?lang=en` en la URL.
3. El idioma del navegador: español si el primero de `es`/`en` es español; si no, inglés.

El selector ES/EN de la cabecera cambia el idioma al momento, sin recargar. `<html lang>` y el título de la pestaña se actualizan.

## Uso

```html
<h1>{{ 'about.title' | t }}</h1>
<p>{{ 'units.minutes' | t: { n: 15 } }}</p>
```

```ts
private readonly i18n = inject(I18nService);
readonly label = computed(() => this.i18n.t('nav.home'));
```

Para formatos dependientes del idioma: `formatMinutes`, `formatDistance`, `formatClock` y `formatNumber`.

## Añadir textos

1. Añade la clave en `messages.es.ts`.
2. Añade la traducción en `messages.en.ts` (el compilador lo exige).
3. Usa la clave con el pipe `t` o con `I18nService.t`.
